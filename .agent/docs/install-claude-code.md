# Installing Claude Code

Claude Code is the recommended AI for this repo — it has full support for slash commands, MCP integrations, and the CLAUDE.md agent constitution.

## 1. Create an Anthropic account
Sign up free at [claude.ai](https://claude.ai). You'll need a paid plan (Claude Pro or higher) to use Claude Code.

## 2. Install the VS Code extension
Inside VS Code, press `Ctrl+Shift+X` (Windows/Linux) or `Cmd+Shift+X` (Mac).
Search **Claude Code**, click **Install**.

Or install directly from the marketplace: [marketplace.visualstudio.com](https://marketplace.visualstudio.com/items?itemName=Anthropic.claude-code)

## 3. Sign in
Click the Claude icon in the VS Code sidebar and sign in with your Anthropic account.

## 4. Return to setup
Go back to the README and continue with step 3 (get this repo).
