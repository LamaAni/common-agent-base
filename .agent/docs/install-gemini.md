# Installing Gemini Code Assist

Gemini Code Assist is Google's AI assistant for VS Code. It works with this repo for chat and task assistance. Slash commands and MCP are not supported.

## 1. Get access
- **Personal / free tier:** available at [idx.google.com](https://idx.google.com) or sign in with any Google account in the extension
- **Google Workspace:** ask your IT admin — Gemini may already be available in your workspace

## 2. Install the VS Code extension
Inside VS Code, press `Ctrl+Shift+X` (Windows/Linux) or `Cmd+Shift+X` (Mac).
Search **Gemini Code Assist**, click **Install** (published by Google).

## 3. Sign in
Click the Gemini icon in the sidebar and sign in with your Google account.

## 4. Return to setup
Go back to the README and continue with step 3 (get this repo).
