# [AGENT_NAME] — Your Personal AI Assistant

This is your personal AI assistant. Give it tasks in plain English and it handles the rest.
Your assistant organises all its outputs in the **Work/** folder.

## What you need

**Claude Code** — download and install it from [claude.ai/code](https://claude.ai/code).

## Getting started

1. Open Claude Code
2. Open this folder (File → Open Folder)
3. Type: _Please follow SETUP.md and set up my workspace._

Setup takes about 10 minutes. Claude will ask your name, your team, and what to call your assistant.

## After setup

Drop a task in plain English. Your assistant puts results in **Work/**, organised by project.
Use `/` to run saved skills (e.g. `/summarize`).
